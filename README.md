# Portfolio Resume

This private repository is the single source of truth for my professional experience, reusable resume material, project stories, and NIW research narrative.

## Structure

- `resume/master.md`: canonical career facts and reusable resume bullets
- `resume/niw-cv.tex`: concise NIW-oriented CV
- `resume/tailored/`: role-specific resume versions generated from the master
- `stories/`: factual project records with technical and leadership context
- `research/`: proposed endeavor, research narrative, national importance, future direction, and evidence map

## Rules

- Preserve factual accuracy; never invent responsibilities, metrics, technologies, or outcomes.
- Use `TODO:` when a detail is unknown or needs confirmation.
- Keep internal service names in story notes; translate them into industry-standard language in public-facing documents.
- Treat `resume/master.md` and the project stories as canonical sources.
- Tailored resumes may select and reframe facts, but must not introduce new claims.
- Ask before deleting or materially rewriting historical information.

## Resume naming convention

Name every resume using:

```text
yyyy-mm-name.ext
```

Examples:

- `2026-07-general.tex`
- `2026-07-niw.tex`
- `2026-08-stripe.pdf`

Use lowercase words separated by hyphens. The name should identify the resume's purpose, target company, or target role.
